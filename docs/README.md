# Sistema Integrado de Gestão de Estoque e Financeiro

## Visão Geral

Este sistema foi projetado para oferecer uma solução abrangente e eficiente para a gestão empresarial, integrando o controle de estoque com um módulo financeiro inovador. Ele possibilita o registro detalhado e o gerenciamento de entrada e saída de produtos, além de acompanhar o fluxo de caixa por meio do rastreamento de pagamentos de boletos. O sistema utiliza um banco de dados local para garantir precisão, organização e acessibilidade às informações, e um com backup salvo local e na nuvem, assegurando a consistência dos dados em casos extremos.

---

## Funcionalidades

### Controle de Estoque
- Permite o registro detalhado e preciso das entradas e saídas de produtos, garantindo a organização e atualização constante do inventário.
  - **Registro Automatizado:** Atualizações rápidas e confiáveis que refletem a movimentação real de produtos.
  - **Consulta Dinâmica:** Ferramentas de visualização que facilitam o monitoramento do estoque em tempo real.

### Gerenciamento Financeiro e Rastreamento de Boletos
- Um módulo financeiro robusto que acompanha e gerencia os pagamentos de boletos, integrando informações financeiras à gestão de estoque.
  - **Monitoramento de Pagamentos:** Rastreie o status de cada boleto—se está pendente, pago ou vencido—garantindo controle rigoroso das obrigações financeiras.
  - **Alertas e Relatórios:** Notificações para vencimentos próximos e geração de relatórios detalhados que facilitam a análise de fluxo de caixa e o planejamento financeiro.
  - **Histórico de Transações:** Registro completo de todas as operações financeiras para consulta e auditoria.
 
### Interface Amigável e Sincronização
- Uma interface intuitiva que torna a operação simples para usuários de todos os níveis, com sincronização contínua dos dados para assegurar a consistência entre diferentes pontos de acesso.
  - **Backup Automático:** Segurança dos dados com a possibilidade de realizar backups de forma prática e imediata.

## Tecnologias Utilizadas

- **Tipo do Sistema**: Aplicativo Windows Executável 
- **IDE**: Visual Studio
- **Banco de Dados**: LiteDB com backup salvo na nuvem
- **Frontend e Backend**: C#
- **Frameworks**: WPF
- **Target Framework**: .NET 8
