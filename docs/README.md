# Sistema de Controle de Estoque

## Visão Geral

Este projeto visa desenvolver um sistema de controle de estoque eficiente e intuitivo, permitindo o registro e gerenciamento de entrada e saída de produtos. O sistema utiliza um banco de dados local e/ou na nuvem para garantir a precisão e a organização das informações de estoque.

## Funcionalidades

- **Controle de Estoque**: Registro preciso de entrada e saída de produtos.
- **Consulta de Estoque**: Visualização e consulta de informações de estoque.
- **Interface Amigável**: Interface de usuário intuitiva e fácil de usar.
- **Sincronização de Dados**: Atualização periódica dos dados para manter a precisão.
- **Backup**: Capacidade de salvar todos os dados em um arquivo para recriação do banco de dados.

## Requisitos

### Funcionais

- Controle preciso do estoque utilizando um banco de dados local.
- Registro de entrada e saída de produtos.
- Desempenho básico adequado para uso cotidiano.

### Não Funcionais

- Interface de usuário intuitiva e fácil de usar.
- Sincronização em tempo real das informações entre o sistema de controle de estoque e o registro de vendas.
- Acessibilidade para diversos tipos de dispositivos.
- Backup dos dados ao clicar em um botão.

## Tecnologias Utilizadas

- **Tipo do Sistema**: Aplicativo Executável
- **IDE**: Visual Studio
- **Banco de Dados**: Firebase
- **Frontend e Backend**: C#
- **Frameworks**: WPF
- **Target Framework**: .NET 8

## Cronograma de Entregas

### Fase 1: Design da Arquitetura

- **Semana 1**: Protótipo inicial da arquitetura.
- **Semana 2**: Revisão e ajustes no protótipo com feedback do cliente.
- **Semana 3**: Entrega do design final da arquitetura.

### Fase 2: Banco de Dados Inicial, Interface Inicial, Cadastro de Produtos

- **Semana 4**: Estrutura inicial do banco de dados.
- **Semana 5**: Protótipo da interface inicial.
- **Semana 6**: Funcionalidade básica de cadastro de produtos.
- **Semana 7**: Integração e testes iniciais das funcionalidades.

### Fase 3: Banco de Dados Preenchido, Entrada e Saída de Produtos, Dashboards

- **Semana 7**: Preenchimento inicial do banco de dados com dados reais.
- **Semana 8**: Funcionalidade de entrada e saída de produtos.
- **Semana 9**: Protótipo inicial dos dashboards.
- **Semana 10**: Testes e ajustes finais das funcionalidades.

### Fase 4: Treinamento, Implementação do Sistema

- **Semana 11**: Sessão de treinamento inicial para os usuários.
- **Semana 12**: Implementação do sistema no ambiente do cliente.
- **Semana 13**: Suporte pós-implementação e ajustes finais.
